Quick Start

How to Install in 60 Seconds

FirstNode runs on any Chromium-based browser (Chrome, Edge, Brave, Opera).

STEP 01
Clone or Download
Download the repository ZIP or run git clone https://github.com/Polymath1234/TRACE.git.
STEP 02
Open Extensions Page
Navigate to chrome://extensions or edge://extensions in your browser.
STEP 03
Enable Developer Mode
Toggle on Developer mode in the top-right corner of the Extensions dashboard.
STEP 04
Load Unpacked
Click Load unpacked and select the directory containing manifest.json.
